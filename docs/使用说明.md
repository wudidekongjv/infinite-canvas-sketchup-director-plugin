# SketchUp ⇄ 3D 导演台 · 同步管线

用 SketchUp 定机位、定遮挡，用 3D 导演台出人物与动作，最后合成一条「SU 场景 + 会动的人」的视频。不用 Blender。

---

## 1. 三个部件

| 部件 | 位置 | 作用 |
| --- | --- | --- |
| SketchUp 插件 `su_to_director` | `C:\Users\32553\AppData\Roaming\SketchUp\SketchUp 2026\SketchUp\Plugins\su_to_director.rb` + 同名文件夹 | 记录机位、插值机位轨道、导出遮挡 OBJ、渲染 SU 背景帧、接收导演台回传帧、调用编码器出片；内置本地 HTTP 服务（默认 `127.0.0.1:37740`） |
| 导演台改造版 | `3d-director-desk-su\`（源码） / `dist\`（构建产物） | 在原版 3D 导演台上加了三块：`SuSyncPanel`（连接面板）、`SuComposeExport`（逐帧透明渲染 + 回传）、`SuOccluderLayer`（SU 遮挡只写深度） |
| 编码器 | `Plugins\su_to_director\tools\encode_video.py` | 把 `composite_*.png` 序列用 ffmpeg 编成 mp4（自动找 `imageio-ffmpeg` 或 PATH 里的 ffmpeg） |

> 你原来的 `su_to_blender.rb` / `su_to_blender\` 完全没动，两套插件互不影响。新插件装的是 `su_to_director.rb` + `su_to_director\` 两个条目，想卸掉删这两个就行。

## 2. 数据怎么走

```
SketchUp                                 3D 导演台（浏览器）
─────────                                ──────────────────
记录起点/终点机位
      │  两点插值 → N 帧（fov 轴自动校准）
      ├──── GET  /su/session ───────►  读机位帧 + 遮挡体地址 + 背景帧模板
导出遮挡几何体 (OBJ)                        │
      ├──── GET  /su/occluders.obj ──►  只写深度不写颜色的遮挡层
渲染背景帧 bg_00000.png …                   │
      ├──── GET  /su/bg/{i}.png ─────►  每帧当底图（同视角同画幅）
                                          │  隐藏画布逐帧渲染：
                                          │  ① 设 SU 机位  ② 推进人物动作
                                          │  ③ 透明背景只画角色（被遮挡层挡掉的部分不画）
                                          │  ④ 叠加 SU 背景帧 → 合成
      ◄──── POST /su/frame/kind=… ────┤  回传 layer_*.png 与 composite_*.png
      ◄──── POST /su/done ────────────┘
点“合成 mp4” → video\composite_24fps_*.mp4
```

坐标和 FOV 是这条链上最容易错的两件事，插件里已经固定下来：

| 项 | 规则 |
| --- | --- |
| 坐标 | SketchUp 英寸 / Z 轴向上 → three.js 米 / Y 轴向上：`(x, y, z) → (x, z, -y) * 0.0254` |
| 相机姿态 | 用 forward/up 构造基向量（不是 lookAt），SU 里带滚转的机位也能一比一对齐 |
| FOV | SU 的 `fov` 可能作用在垂直也可能在水平方向，插件用 `screen_coords` 探点自动判定，再换算成 three.js 的垂直 fov |
| 画幅 | 导演台导出画布固定取 SU 的 `width / height`，和背景帧同像素尺寸，所以能直接叠 |

## 3. 装好了，怎么用（四步）

1. **重启 SketchUp** → 菜单 `扩展程序 → SU ⇄ 3D 导演台 → 打开同步面板`。
2. **定机位**：把视图摆到起点 → 点「记录起点机位」；摆到终点 → 点「记录终点机位」→ 设时长/帧率/分辨率 → 点「生成机位轨道」。
   - 状态栏会显示 `N 帧 / fps / 秒 / 宽×高 / FOV=vertical|horizontal`。
3. **出素材**：
   - 选中要当遮挡体的墙、楼板、柱子 → 「导出遮挡模型 (OBJ)」（或切成「整个可见模型」）；
   - 「渲染背景帧」——期间 SketchUp 会被逐帧占用，别去动窗口，渲完相机自动还原；嫌久可点「停止」。
4. **联调**：面板里点「启动服务」→ 打开导演台页面（带 `?suBridge=http://127.0.0.1:37740`）→ 面板点「连接」→ 「合成导出到 SketchUp」→ 回 SU 点「合成 mp4」。

导演台页面两种打开方式：

```powershell
# 方式一：跑构建产物（推荐，快）
cd C:\Users\32553\Doubao\chats\2026-11-06\new-chat\3d-director-desk-su
npx vite preview --port 5199 --strictPort
# 浏览器打开： http://127.0.0.1:5199/?suBridge=http://127.0.0.1:37740

# 方式二：开发模式（改代码时用）
npm run dev
```

## 4. 导演台里那几个开关

| 开关 | 默认 | 含义 |
| --- | --- | --- |
| 相机跟随 SketchUp 机位 | 开 | 主视口/相机视图用 SU 的机位帧，不再用导演台自己的相机运动 |
| 启用 SU 遮挡体（导出时生效） | 开 | 隐藏画布里挂遮挡层，只写深度 |
| 主视口也显示遮挡 | 关 | 开了以后主视口会被"看不见的墙"挡住人物，只用于核对 |
| 连导演台道具一起导出 | 关 | 关＝只导人物；开＝把导演台里摆的道具也并进角色层 |

## 5. 排错

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 面板点连接一直转圈 | 服务没起 / 端口被占 | SU 里点「启动服务」；被占就改 `Plugins\su_to_director\config.json` 的 `port`，导演台地址同步改 |
| 连接报 CORS / 混合内容 | 导演台页面是 `https://` | 用 `http://127.0.0.1:5199` 打开导演台，浏览器不允许 https 页面访问 `http://127.0.0.1` |
| 人物和 SU 场景对不上 | 画幅比例不一致 / FOV 轴判错 | 重建轨道时保持 SU 窗口接近目标比例；FOV 轴别选"自动"时手动试 vertical/horizontal |
| 人物整块消失 | 遮挡体把 SU 场景里的墙也导进来了，档在镜头和人物之间 | 关「启用 SU 遮挡体」核对；或只选真正该挡人的构件导出 |
| 导出到一半失败 | 某一帧 PNG 太大 / 服务被打断 | 面板日志会显示到第几帧；降低分辨率重试 |
| 「合成 mp4」失败 | 没 python 或没 imageio-ffmpeg | `python -m pip install imageio-ffmpeg`；或设环境变量 `SU_TO_DIRECTOR_FFMPEG=D:\ffmpeg\bin\ffmpeg.exe`；python 不在 PATH 时设 `SU_TO_DIRECTOR_PYTHON` |
| 帧序对不上 / 少了首尾 | 帧号从 0 开始 | 编码器固定 `-start_number 0`，别手工改文件名 |

## 6. 这一版的边界（说清楚，免得你以为坏了）

| 项 | 现状 |
| --- | --- |
| 机位 | 只支持「起点 + 终点」两点插值（缓入缓出 / 线性）。SU 里多机位序列还没做 |
| 遮挡精度 | 遮挡体是逐面片 OBJ，超大模型有面数上限（默认 40 万面，可调），超了会截断并提示 |
| 光影 | 角色层是透明背景单独渲染，**不接收 SU 场景的阴影**，人物脚下没有接触阴影；需要的话下一步在 SU 侧烘一张 AO 或在导演台加假阴影 |
| 视频 | 只出 mp4（H.264），没有音轨；需要配音就后期合 |
| 无限画布 | 导演台页面本身就能跑，改装版画布只当容器用；本轮没有改 `F:\SD\胡师傅多开浏览器` 里的任何文件 |
